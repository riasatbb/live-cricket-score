1

Create a Firebase project

Go to console.firebase.google.com, open a project on the free plan, then go to Build → Realtime Database → Create Database (Start in test mode). In the database Rules, make sure the liveMatch path is publicly readable and writable — this page reads and writes all score data at that exact path:
{ "rules": { "liveMatch": { ".read": true, ".write": true } } }

2

Add a web app and copy the config

Project Settings → Add app → Web (</>) — you will get an object called firebaseConfig (with apiKey, databaseURL, and more). Copy it and paste it into the box below.

3

Connect here

Paste the config below and tap “Connect to Firebase” — this page then links to the live database. Every ball from the scorer goes to the database, and anyone with the scoreboard or overlay open receives it instantly.

4

Host this page on GitHub Pages (for a public link)

Put this page file in a GitHub repo and turn on Settings → Pages to get a free public link. Give viewers the …/?view=scoreboard link, put the …/?view=overlay link in OBS, and score on the …/?view=scorer page — all three read the same Firebase data.

Add a Browser Source

In OBS, go to Sources → + → Browser and paste your page's overlay link as the URL (after hosting it on GitHub Pages):

https://your-name.github.io/live-cricket-score/?view=overlay
2

Set the size

Set Width 1920 and Height 1080. The overlay page background is transparent, so the score bar floats directly over the video — preview it below in “transparent background” mode.

3

Score once, update in two places

Now score a ball on the Scorer page from your phone or laptop and both the Public Scoreboard and the OBS score bar change instantly. No refresh needed.
